# Klaroh Brand Guidelines

## Brand Identity

**Klaroh** is a client visibility platform for lead generation agencies. The brand represents transparency, trust, and real-time insights through sophisticated dashboard design.

### Brand Values
- **Transparency**: Real-time, honest reporting that clients can trust
- **Clarity**: Clear visualization of campaign performance metrics
- **Trust**: Building absolute client confidence through data
- **Sophistication**: Premium, polished user experience for agencies

### Brand Voice
Professional, confident, and data-driven. Klaroh speaks to agency leaders who value precision and client relationships.

## Visual Design System

### Color Palette (Material 3)
- **Primary**: #003E2A (deep green - actions and chrome: buttons, sidebar, focus)
- **Primary Container**: #0F573E (brand green for data: charts, meters, "good")
- **Secondary**: #545F73
- **Error / Critical**: #BA1A1A (for destructive actions)
- **Surface**: #F8F9FF (page background); cards are #FFFFFF
- Full token set (status, chart, radius, spacing): `src/app/globals.css` and `docs/design.md`

### Typography
- **Page titles**: Instrument Serif (italic, 400) via `.type-page-title`, 28-32px
- **Everything else**: Inter (400, 500, 600) - section titles 16px semibold, body 14px, tables 13px, captions 12px (never smaller)
- **Font sizes**: 13.125px for nested nav

### Component Style
- Rounded corners (8px radius)
- Subtle shadows and borders
- Clean, spacious layouts
- Left border indicators for active states

## Brand Applications

### Dashboard Experience
- Real-time campaign performance tracking
- Aggregated metrics across campaigns
- Client-specific views with transparent metrics
- Centralized campaign management

### Navigation Philosophy
- Nested client lists for quick access
- Campaign-centric organization
- Immediate campaign creation workflows
- Settings and integration management
